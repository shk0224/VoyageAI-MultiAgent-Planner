# VoyageAI-MultiAgent-Planner
An AI-powered multi-agent travel planning system built with LangGraph, featuring flight and hotel discovery, personalized itineraries, budget optimization, and persistent memory.

## How to run?
1. create the virtual env
conda create -n travel python=3.11 -y
2. activate the env
conda activate travel
3. Install all reqs
pip install -r requirements.txt
